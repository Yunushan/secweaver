# Changelog

All notable project changes are recorded here.

## 0.1.0 - 2026-07-28

- Initial dependency-free SecWeaver orchestrator and policy engine.
- Gitleaks, Trivy, Opengrep, OSV-Scanner, and CycloneDX adapters.
- Sanitized JSON, Markdown, JUnit, SARIF, verdict, and manifest reports.
- Advisory, balanced, strict, enterprise-overlay, and air-gapped examples.
- Portable CI/CD templates for major hosted, self-hosted, and Kubernetes tools.
- Fifty-language catalog with a maintained Tier-1 set of twenty.
- Linux, Windows/Windows Server, macOS, FreeBSD, and Android-project guidance.
- 0BSD licensing for original project material.
