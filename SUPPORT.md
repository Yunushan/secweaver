# Support

SecWeaver is community-maintained alpha software. Use public issues for
sanitized bug reports, documentation problems, and feature proposals. Use the
private process in `SECURITY.md` for vulnerabilities or possible data exposure.

When requesting help, include the SecWeaver version, host operating system,
Python version, scanner versions, execution mode, policy profile, and a minimal
sanitized reproduction. Do not attach raw reports from a private project.

Platform support means that the orchestrator and wrapper are portable.
Availability and behavior of external scanner binaries must be checked against
their pinned release. The machine-readable boundaries are in
`support-matrix.json`.
